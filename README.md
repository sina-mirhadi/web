# سایت شخصی سینا
سایت استاتیک چندصفحه‌ای (HTML/CSS/JS + Three.js از CDN). نیازی به build ندارد.

صفحه‌ها: index.html، about.html، faq.html، certs.html، 404.html
فایل‌ها: common.js (منو، فوتر، ترمینال، شوخی‌ها)، home.js (هیرو، سه‌بعدی، دکمه‌ی فرار)

- تست محلی: `python -m http.server 8000`
- دیپلوی: Netlify، Vercel، Cloudflare Pages یا GitHub Pages. فایل 404.html را این سرویس‌ها خودکار استفاده می‌کنند.
- تغییر آیدی تلگرام: عبارت ForExampleSina را در index.html عوض کنید.
